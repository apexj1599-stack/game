# Emberfall

A polished 2-player arena survival game.

## Gameplay
- 30-wave campaign with six bosses
- Solo or local 2-player co-op
- Eight weapons and 18 perks
- Permanent meta progression
- Endless mode unlocked at wave 10
- Procedural enemy compositions and escalating difficulty

## Development

```bash
npm install
npm run dev
npm run build
```

The project is being actively debugged and polished with a focus on responsive combat, a smooth difficulty curve, replayability, and a premium game UI.
